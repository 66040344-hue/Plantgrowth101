# Plant Growth Logger — ระบบเก็บภาพการเจริญเติบโตของพืช

หน้าเว็บ (HTML/CSS/JS ล้วน) สำหรับถ่ายภาพพืชแยกตาม สวน → วันที่ → ทรีตเมนต์ → ตัวอย่าง
ภาพเก็บใน Google Drive และข้อมูลเก็บใน Google Sheet ผ่าน Google Apps Script (ฟรี)

```
มือถือ (เว็บ + แอปกล้องของเครื่อง) ──▶ Google Apps Script ──▶ Google Drive (ภาพ)
       │ เก็บภาพในเครื่องก่อน (ออฟไลน์ได้)                └──▶ Google Sheet (ข้อมูล)
```

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `css/style.css`, `js/app.js` | หน้าเว็บหลัก |
| `js/config.js` | **ต้องแก้** — URL ของ Apps Script และ APP_KEY |
| `js/db.js` | เก็บภาพในเครื่อง (IndexedDB) สำหรับโหมดออฟไลน์ |
| `js/api.js` | เชื่อมต่อ Apps Script |
| `sw.js`, `manifest.json` | ทำให้เปิดเว็บได้ตอนออฟไลน์ / ติดตั้งเป็นแอปได้ |
| `qr.html` | สร้างและพิมพ์ QR Code ติดกระถาง |
| `apps-script/Code.gs` | โค้ดฝั่ง Google (วางใน Apps Script) |

---

## ขั้นตอนติดตั้ง

### 1. สร้าง Google Sheet และ Apps Script
1. ไปที่ Google Drive ของบัญชีที่จะใช้เก็บภาพ แล้วสร้าง **Google Sheet** ใหม่ ตั้งชื่อเช่น `PlantGrowth DB`
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมออก แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
4. แก้ `APP_KEY` ที่บรรทัดบน ๆ เป็นรหัสลับของตัวเอง เช่น `egat-plant-2026-x9k2`
5. (ถ้าต้องการ) ใส่ `ROOT_FOLDER_ID` เป็น ID ของโฟลเดอร์ที่มีอยู่แล้ว ถ้าเว้นว่างไว้ ระบบจะสร้างโฟลเดอร์ `PlantGrowth` ให้เอง
6. กด 💾 Save แล้วเลือกฟังก์ชัน **`setup`** → กด **Run**
   - ครั้งแรกจะขอสิทธิ์: Review permissions → เลือกบัญชี → Advanced → Go to ... (unsafe) → Allow
   - ระบบจะสร้างชีต `Config`, `Photos`, `Sessions` และโฟลเดอร์ใน Drive ให้

### 2. ตั้งค่าสวน/ทรีตเมนต์

**ทำผ่านหน้าเว็บได้เลย:** ตั้งค่า → ✏️ **จัดการสวน / ทรีตเมนต์** → เพิ่มหรือแก้ไขสวน ทรีตเมนต์ จำนวนต้น จำนวนกิ่ง → 💾 บันทึก
- รหัสสวนและรหัสทรีตเมนต์ที่บันทึกแล้วจะแก้ไม่ได้ (ใช้ในชื่อไฟล์และ QR) แต่เปลี่ยนชื่อสวน จำนวนต้น และจำนวนกิ่งได้
- ถ้าต้องการจำกัดคนแก้ไข ให้ใส่ `ADMIN_PIN` ใน `Code.gs` หน้าเว็บจะถาม PIN ตอนบันทึก (ถามครั้งเดียวแล้วจำไว้ในเครื่อง)
- ถ้ามีคนแก้ไขพร้อมกัน ระบบจะไม่ให้บันทึกทับ และให้โหลดค่าล่าสุดก่อน

ข้อมูลเก็บอยู่ในชีต `Config` (แก้ในชีตโดยตรงก็ยังได้):

| garden_id | garden_name | treatment | samples | branches |
|---|---|---|---|---|
| GA | สวน A | T1 | 5 | 4 |
| GA | สวน A | T2 | 5 | 4 |
| GB | สวน B | T1 | 3 | 4 |

- 1 แถว = 1 ทรีตเมนต์ในสวนนั้น
- `garden_id` ใช้ภาษาอังกฤษหรือตัวเลขสั้น ๆ (ใช้ในชื่อไฟล์และ QR) ส่วน `garden_name` ใช้ภาษาไทยได้ (ใช้เป็นชื่อโฟลเดอร์)
- `samples` = จำนวนต้น ระบบจะตั้งชื่อเป็น T1P1, T1P2, ...
- `branches` = จำนวนกิ่งที่ถ่าย (กิ่งละ 2 ภาพ คือชุดใบและใบเดี่ยว)
- ถ้าแก้ในชีตโดยตรง ให้กด "โหลดใหม่" ในหน้าตั้งค่าของเว็บ

### 3. Deploy เป็น Web App
1. ใน Apps Script กด **Deploy → New deployment**
2. ⚙️ Select type → **Web app**
3. Execute as: **Me** / Who has access: **Anyone**
4. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> **แก้โค้ด Apps Script ภายหลัง:** ใช้ Deploy → **Manage deployments** → ✏️ Edit → Version: **New version** → Deploy
> URL จะเหมือนเดิม (ถ้าใช้ New deployment จะได้ URL ใหม่)

### 4. แก้ `js/config.js`
```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfy..../exec',
  APP_KEY: 'egat-plant-2026-x9k2',   // ต้องตรงกับใน Code.gs
};
```

### 5. นำหน้าเว็บขึ้น Host (GitHub Pages — ฟรี)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (ยกเว้นโฟลเดอร์ `apps-script` จะใส่ไปด้วยหรือไม่ก็ได้)
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / root → Save
3. รอประมาณ 1 นาที จะได้ URL เช่น `https://<user>.github.io/<repo>/`

ใช้ Netlify, Cloudflare Pages หรือ Vercel แทนก็ได้ (ลากโฟลเดอร์ขึ้นไปได้เลย) แต่**ต้องเป็น HTTPS** เพราะโหมดออฟไลน์ต้องใช้

> **อัปเดตหน้าเว็บ:** หลังแก้ไฟล์ ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น `v1` → `v2`) เพื่อให้มือถือโหลดไฟล์ใหม่

### 6. พิมพ์ QR Code
เปิดเว็บ → ตั้งค่า → **พิมพ์ QR Code** → เลือกสวน/ทรีตเมนต์ → พิมพ์ (4 ดวงต่อแถวบนกระดาษ A4)

## วิธีใช้งาน
1. สแกน QR ที่กระถางด้วยแอปกล้องของมือถือ (หรือเลือกสวนและต้นจากหน้าหลัก)
2. แตะแต่ละช่อง → แอปกล้องของเครื่องจะเปิดขึ้นมา → ถ่ายภาพ → ภาพจะกลับมาแสดงในช่อง
   - แตะช่องเดิมเพื่อถ่ายใหม่ หรือกด ✕ เพื่อลบ
3. กด **💾 บันทึก** → ระบบอัปโหลดเบื้องหลัง → กด **ต้นถัดไป**
4. ถ้าไม่มีสัญญาณ ภาพจะเก็บไว้ในเครื่อง และอัปโหลดให้อัตโนมัติเมื่อกลับมาออนไลน์ (ดูสถานะได้ที่ "คิวอัปโหลด")

สีของต้นในหน้าหลัก: ⬜ ยังไม่ถ่าย · 🟨 ถ่ายแล้วแต่ยังไม่บันทึก · 🟦 รออัปโหลด · 🟩 เสร็จแล้ว (รวมต้นที่คนอื่นบันทึกด้วย)

### ถ่ายต่อ / ไม่อัปโหลดซ้ำ
- เปิดต้นไหน ระบบจะดึงรายการภาพที่อยู่บน Drive แล้ว (รวมถึงภาพที่เครื่องอื่นถ่าย) พร้อมภาพย่อมาแสดงในช่อง (☁️ อยู่บน Drive แล้ว) ให้ถ่ายเฉพาะช่องที่ยังขาด
- บันทึกได้แม้ภาพยังไม่ครบ แล้วกลับมาถ่ายต่อภายหลังได้ ภาพเดิมจะไม่ถูกส่งซ้ำ
- ถ้าเน็ตหลุดระหว่างส่ง ภาพที่ขึ้น Drive ไปแล้วจะถูกข้าม ไม่ส่งซ้ำ
- 🖼️ มุมซ้ายบนของแต่ละช่อง = เลือกภาพจากคลังภาพ (กรณีถ่ายด้วยกล้องไว้ก่อนแล้ว)

### รอบการเก็บข้อมูล / ดูย้อนหลัง
- หน้าหลักแสดง **รอบการเก็บข้อมูล** ทั้งหมดของสวน (วันนี้ + รอบที่เคยเก็บ พร้อมจำนวนต้นที่เก็บแล้ว) แตะเพื่อสลับรอบ หรือกด "วันอื่น" เพื่อเลือกวันที่เอง
- รอบที่ไม่ใช่วันนี้จะเป็น **โหมดดูอย่างเดียว** แตะภาพเพื่อดู ถ้าต้องการแก้ไข/ถ่ายเพิ่มให้กด "แก้ไขรอบนี้"
- ช่องที่มีภาพแล้ว แตะเพื่อเปิดดู → ถ่ายใหม่แทน / เลือกจากคลังภาพ / เปิดใน Google Drive (ป้องกันการถ่ายทับโดยไม่ตั้งใจ)
- ถ้าเครื่องล็อกอิน Google ด้วยบัญชีที่มีสิทธิ์ในโฟลเดอร์ หน้าดูภาพจะโหลดภาพความละเอียดสูงจาก Drive ให้อัตโนมัติ

### ประวัติการเจริญเติบโต
- ในหน้าต้น กด **ประวัติ** เพื่อดูภาพของต้นเดียวกันทุกรอบ เลือกตำแหน่งได้ (ภาพต้น, กิ่ง 1 ชุดใบ, …)
- แต่ละรอบบอกวันที่และ "วันที่ N" นับจากรอบแรก แตะเพื่อดูภาพใหญ่ และเลื่อนรอบก่อน/ถัดไปได้

## การอัปโหลด
- มือถือส่งไฟล์ภาพ**ตรงเข้า Google Drive** (resumable upload) โดยไม่ต้องแปลงเป็น base64 จึงใช้ RAM น้อยและเร็วกว่า ส่งพร้อมกันครั้งละ 3 ภาพ
- ถ้าส่งตรงไม่ได้ ระบบจะสลับไปใช้วิธีสำรอง (ผ่าน Apps Script) ให้อัตโนมัติ

## อัปเดตจากเวอร์ชันก่อน
1. วางโค้ด `apps-script/Code.gs` ใหม่ทับใน Apps Script (คงค่า `APP_KEY` / `ROOT_FOLDER_ID` เดิมไว้)
2. Run ฟังก์ชัน **`setup`** อีกครั้ง เพื่อเพิ่มคอลัมน์ `thumb` และอนุญาตสิทธิ์ใหม่ ("เชื่อมต่อบริการภายนอก")
3. Deploy → **Manage deployments** → ✏️ → Version: **New version** → Deploy (URL เดิม)
4. อัปโหลดไฟล์เว็บชุดใหม่ขึ้น host ทุกไฟล์ (รวม `js/icons.js` ที่เพิ่มใหม่) — `sw.js` เปลี่ยนเวอร์ชันแล้ว

## ผลลัพธ์ใน Google Drive
```
PlantGrowth/
 └─ สวน A/
     └─ 2026-10-30/
         └─ T1/
             └─ T1P1/
```

- ชีต `Photos` มี 1 แถวต่อ 1 ภาพ (มีลิงก์ไฟล์) และชีต `Sessions` มี 1 แถวต่อ 1 ต้นต่อ 1 รอบ (พร้อมหมายเหตุ)
- ถ้าถ่ายใหม่แล้วส่งซ้ำ ไฟล์เดิมจะถูกย้ายไปถังขยะ (กู้คืนได้ภายใน 30 วัน)

## ข้อควรรู้
- **พื้นที่ Drive:** ภาพเต็มความละเอียดมีขนาดประมาณ 3–6 MB ต่อภาพ ต้นที่มี 4 กิ่งจะได้ 9 ภาพ หรือราว 30–50 MB ต่อต้นต่อรอบ
  ตัวอย่าง: 100 ต้น × 2 รอบ/เดือน ≈ 6–10 GB/เดือน บัญชี Gmail ส่วนตัว (15 GB) จะเต็มเร็ว จึงแนะนำให้ใช้บัญชีสถาบัน
  หรือเลือก "ย่อด้านยาว 3000px" ในหน้าตั้งค่า ซึ่งจะเหลือประมาณ 1–1.5 MB ต่อภาพ
- **บัญชีสถาบัน:** บาง Google Workspace ไม่อนุญาตให้ตั้ง Who has access เป็น "Anyone" ถ้าไม่มีตัวเลือกนี้ ให้ติดต่อผู้ดูแลระบบ หรือใช้บัญชี Gmail ส่วนตัวแทน
- **ความปลอดภัย:** APP_KEY อยู่ในไฟล์ JS ที่ทุกคนเปิดดูได้ จึงกันได้แค่คนทั่วไปที่ไม่รู้ URL ห้ามแชร์ลิงก์เว็บสาธารณะ ถ้าต้องการความปลอดภัยมากกว่านี้ค่อยเพิ่มระบบ Login ภายหลัง
- **iPhone:** ถ้า "เพิ่มไปยังหน้าจอโฮม" ข้อมูลในแอปจะแยกจากข้อมูลใน Safari ส่วน QR จะเปิดใน Safari เสมอ จึงแนะนำให้ใช้ผ่าน Safari อย่างเดียว
- **อย่าล้างข้อมูลเบราว์เซอร์** ขณะที่ยังมีภาพค้างในคิวอัปโหลด
- มือถือที่ RAM น้อยบางรุ่นอาจรีโหลดหน้าเว็บหลังเปิดกล้อง ภาพที่ถ่ายไปก่อนหน้าจะยังอยู่ครบ (บันทึกลงเครื่องทันทีทุกภาพ) แต่ภาพล่าสุดอาจต้องถ่ายใหม่
